# Dear Next · 디어넥스트

내가 고른 기록으로 **올해의 나를 돌아보고, 내년의 작은 실행계획을 만드는** 개인 회고 스킬입니다.

![가상 기록으로 만든 Dear Next 회고 화면](docs/demo.png)

*실제 개인 기록이 아닌 합성 데이터 예시입니다.*

## 이렇게 시작하세요

Claude Code 또는 Codex에 아래 문장을 복사하세요.

> https://github.com/JetProc/dear-next 의 안내를 읽고 디어넥스트를 설치해서 올해의 나와 내년 계획을 만들어 줘. 지금 제공한 기록으로 먼저 만들고, 부족한 내용은 나중에 보완하게 해 줘. 기록이 없으면 내 분석이 아닌 예시라고 표시해 줘. 허용된 작업 공간의 새 폴더에 저장하고 결과를 열어 줘. 내 다른 대화는 찾지 말고, 결과를 인터넷에 공개하지 마.

AI가 [설치 안내](INSTALL.md)를 따라 도와줍니다. 기록이 있으면 초안을, 없으면 명확히 표시된 예시를 먼저 받아요. 원할 때 기록을 더하거나 질문에 답해 보완할 수 있어요. 평소 쓰던 AI에서 [맥락을 요약해 가져오는 방법](skills/dear-next/references/bridge-prompt.md)도 있습니다.

## 이런 결과를 받아요

- **올해의 나:** 삶의 선택·가치·변화를 돌아보는 발견과 그 근거.
- **다음 해의 방향:** 이어갈 것과 바꿀 것, 첫 달 목표와 첫 주 행동 세 가지.
- **간직할 한 장:** 내가 고르고 미리보기로 확인한 문장만 담은 PNG/SVG 카드.

회고는 내 컴퓨터에서 열리는 HTML로 받아요. 맞지 않는 문장은 ‘내 말로 고치기’에서 수정하고, 저장해 다시 만들 수 있습니다.

## 시작 전에 알아두세요

**Claude Code·Codex용입니다.** 로그인과 파일 실행 권한, Node.js 20+, 설치 시 인터넷 연결이 필요합니다. 별도 모델 API 키나 서버는 요구하지 않습니다. Codex 실제 생성은 검증했고, Claude는 테스트 환경의 로그인 부재로 실제 분석까지 검증하지 못했습니다. [지원·검증 범위](docs/verification.md)

선택한 자료의 **AI 분석은 사용 중인 호스트에서 해당 정책에 따라 처리**됩니다. 다른 대화나 개인 기록을 자동 탐색하지 않으며, 결과를 자동 공개하지 않습니다. 상세 회고는 비공개로 보관하고 공유할 카드의 내용만 직접 확인해 주세요. [개인정보와 보안](SECURITY.md)
